## Jonathan Aaris Henningsen

I'm an IT consultant at [Perspektiva IT](https://perspektiva-it.dk) in Denmark. Most days I look after our datacenter: the Nutanix cluster we host customers on, HYCU backups, Fortinet firewalls and quite a lot of AlmaLinux.

I started in 2020 as an IT supporter trainee on Bornholm and did my apprenticeship as a datatekniker (infrastructure) there.

At home I run Proxmox, TrueNAS and a FortiGate 71G. Most of the code here started as something I needed for that setup.

**Things I've built**

- [Homelabrrr](https://github.com/jonarihen/Homelabrrr): a self-service portal for my Proxmox and FortiGate setup. Users get their own VMs with a browser console and SFTP, and I get one place to manage VLANs and firewall rules.
- [caddy-forticertsync](https://github.com/jonarihen/caddy-forticertsync): a Caddy plugin that pushes renewed certificates to a FortiGate. There was already a Windows tool for this, but I wanted it on Linux without a cron job.
- [tools-platform](https://github.com/jonarihen/tools-platform): the code behind [tools.aaris.tech](https://tools.aaris.tech), a few small web tools including a Danish traffic fine calculator and an EPUB to PDF converter.

Certified in Nutanix (NCP-MCI), Fortinet (FCP Secure Networking, FortiGate, FortiManager) and HYCU.
